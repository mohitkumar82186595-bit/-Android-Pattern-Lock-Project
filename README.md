# -Android-Pattern-Lock-Project
🔒 **Android Pattern Lock UI using HTML, CSS & JavaScript**

Excited to share my latest frontend project—an interactive **Android-inspired Pattern Lock** built from scratch using **HTML, CSS, and JavaScript**.

✨ **Key Features:**
🔹 Interactive 3×3 pattern lock grid
🔹 Drag-to-connect pattern drawing
🔹 SVG-based connecting lines
🔹 Correct & incorrect pattern validation
🔹 Smooth animations and glowing effects
🔹 Full-screen **"UNLOCKED"** success screen
🔹 Responsive design for desktop and mobile
🔹 Pure HTML, CSS & JavaScript (No libraries)

This project helped me practice **DOM manipulation, mouse & touch events, SVG graphics, animations, and JavaScript logic** while recreating a familiar mobile security interface.

💻 **Tech Stack:**
• HTML5
• CSS3
• JavaScript (ES6)
